# 周辺状況アナライザー

日時と場所（緯度経度 または 住所・地名）を入力すると、**Claude + Web検索**で周辺の状況を調査し、
**サマリーから始まる重要度順のレポート**を表示するスマホ向けWebアプリです。
レポートに登場した地名は **地図（OpenStreetMap）にピン表示** します。

指定プロンプト（人流アノマリー分析／災害・周辺状況把握）をそのまま組み込んでいます。

## 主な仕様

- **入力式**: 日時・緯度経度・住所は手入力（自動取得しません）。
- **地図表示**: レポート内に出てきた地名をジオコーディングして地図にピン表示。指定地点は赤い点で表示。
- **重要度順のセクション構成**: レポートは必ず「サマリー」から始まり、以降は重要度の高い順に並びます。
- **段階的開示**: 1セクション表示するごとに「このあとに〇〇というセクションがありますが表示しますか？」と確認し、
  「はい」で次のセクションを表示します（「いいえ」でも「続きを表示」から再開可能）。
- **2つの分析モード**:
  - 人流アノマリー分析
  - 災害・周辺状況把握（道路状況・断水・停電・土砂崩れ・建造物被害・避難所・給水所・医療機関 など）
- **PWA対応**: スマホのホーム画面に追加してアプリのように使えます。

## 使い方

1. GitHub Pages などのHTTPS環境で `index.html` を開く（下記「公開方法」参照）。
2. 右上の ⚙︎（設定）から **Anthropic APIキー** を入力して保存。
   - モデルは Claude Opus 5（高精度）／ Claude Sonnet 5（高速・低コスト）から選択。
3. **日時**、**場所**（緯度経度 or 住所）、**分析モード** を入力し「調査を開始」。
4. サマリーと地図が表示され、続きのセクションは確認しながら表示されます。

## 公開方法（GitHub Pages）

このリポジトリの Settings → Pages で、ブランチを選び `/ (root)` を公開ディレクトリに設定するだけで動作します。
ビルド不要の静的サイトです（HTML/CSS/JS のみ）。

ローカル確認は、任意の静的サーバーで:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## セキュリティ / 注意

- **APIキーはこの端末のブラウザ（localStorage）にのみ保存**され、Anthropic以外へ送信されません。
  共有端末では利用後に設定の「キーを消去」を押してください。
- ブラウザから直接 Anthropic API を呼ぶため `anthropic-dangerous-direct-browser-access` ヘッダを使用します。
  キーが端末に残る点を理解した上で、個人利用の範囲でお使いください。本番運用ではAPI中継用のバックエンドを挟むことを推奨します。
- 分析は **AIとWeb検索に基づく推定を含みます**。緊急時・災害時は必ず自治体や公式機関の一次情報を確認してください。

## 使用ライブラリ（CDN）

- [Leaflet](https://leafletjs.com/) + OpenStreetMap タイル（地図）
- [Nominatim](https://nominatim.org/)（地名 → 緯度経度のジオコーディング。1秒1リクエストの利用ポリシーを尊重）
- [marked](https://marked.js.org/) + [DOMPurify](https://github.com/cure53/DOMPurify)（Markdown表示）
